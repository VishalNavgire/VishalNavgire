### 👨‍💻 About Me

With over **12+ years of experience** in the IT industry, I specialize in streamlining complex infrastructure through automation. My core focus lies in modern endpoint management, identity access, and building programmatic solutions that eliminate manual operational toil.

- 🚀 **Core Expertise:** Windows Infrastructure, Microsoft Intune, Autopilot, and Entra ID.
- ⚙️ **Automation Arsenal:** PowerShell, Python (FastAPI, Streamlit, Pandas), Azure Automation Runbooks, and Microsoft Graph APIs.
- 🔭 **Currently Working On:** Azure Functions and running Windows/Linux VMs on my Fedora/KVM home lab environment.
- 🌱 **Upcoming Learning & Skill Goals:** Expanding infrastructure-as-code (IaC) capabilities using **Terraform** and **Ansible**; and **Docker Containers**.
- 🏆 **Recent Achievements:** Developed custom interactive dashboards for Intune/Entra ID management and successfully automated extensive infrastructure deployment workflows to reduce manual overhead across the organization.
